# ربط «وطني ومولدة» بحساب Google (Google Sheet)

كل زبون له **ملف Google Sheet داخل حسابه هو**. الجهاز يكتب فيه مباشرة، والتطبيق يقرأ منه. لا يوجد أي خادم آخر، ولا يرى البيانات أحد غير صاحب الحساب.

## أولًا: تجهيز القالب (مرة واحدة فقط، من حسابك أنت كبائع)
1. افتح [sheets.new](https://sheets.new) ← سمِّ الملف **وطني ومولدة**.
2. من **ملف ← الإعدادات** اجعل المنطقة الزمنية **(GMT+03:00) Baghdad** ← حفظ.
3. **الإضافات ← Apps Script** ← احذف كل ما في `Code.gs` والصق محتوى ملف [`Code.gs`](Code.gs) ← 💾 حفظ.
4. ارجع للملف ← **مشاركة** ← «أي شخص لديه الرابط» (عارض) ← انسخ الرابط.
5. غيّر نهاية الرابط من `/edit?usp=sharing` إلى **`/copy`**. هذا هو **رابط النسخ** الذي تعطيه لكل زبون.

## ثانيًا: عند كل زبون (5 دقائق، من حساب الزبون)
1. افتح **رابط النسخ** وحساب Gmail الزبون مسجَّل ← **إنشاء نسخة**.
2. في النسخة: **الإضافات ← Apps Script** ← زر **نشر (Deploy) ← نشر جديد (New deployment)**.
3. ⚙️ نوع النشر: **تطبيق ويب (Web app)**:
   - التنفيذ باسم (Execute as): **أنا (Me)**
   - من لديه حق الوصول (Who has access): **أي شخص (Anyone)**
   ← **نشر** ← **منح الإذن** ← اختر الحساب ← «Advanced / متقدّم» ← «Go to … (unsafe)» ← **Allow**.
   > التحذير طبيعي لأن السكربت خاص بالزبون وليس منشورًا في متجر Google.
4. انسخ **رابط Web app** (ينتهي بـ `/exec`).
5. ارجع للملف وحدّث الصفحة ← تظهر قائمة **⚡ وطني ومولدة** ← **الإعداد والروابط** ← الصق الرابط إذا طُلب.
6. تظهر نافذة فيها:
   - **رابط التطبيق + QR** ← يفتحه الزبون من موبايله ويضغط 📲 للتثبيت.
   - **Script URL** و **Device key** ← تُلصق في صفحة إعداد الجهاز `Watani-Setup`.
7. في ورقة **الإعدادات** اكتب اسم البيت، وأزل علامة «يوجد اشتراك مولدة» إذا لم يكن عنده مولدة.

## ما الذي يراه الزبون في الملف؟
- ورقة **السجل**: كل انقطاع (الوطنية/المولدة) مع وقت البداية والنهاية والمدة بالدقائق. يمكنه الفرز، الطباعة، أو التحميل Excel من **ملف ← تنزيل**.
- لا تحذف عمود الخط أو تغيّر اسمَي الورقتين **السجل** و **الإعدادات**.

## الأمان
- رابط التطبيق يحوي **مفتاح عرض**، والجهاز يستعمل **مفتاحًا آخر** للكتابة.
- إذا انتشر الرابط: القائمة ← **مفاتيح جديدة** ← أعطِ أهل البيت الرابط الجديد وأدخل المفتاح الجديد في الجهاز.
- عند تعديل `Code.gs` لاحقًا: **نشر ← إدارة عمليات النشر ← ✏️ ← الإصدار: جديد ← نشر** (يبقى نفس الرابط).

## حدود Google المجانية
الجهاز يرسل كل 60 ثانية + فورًا عند أي تغيّر، وهذا ضمن الحدود المجانية لحساب Gmail العادي بفارق كبير.
