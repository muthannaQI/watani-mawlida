# وطني ومولدة ⚡⚙️

تطبيق + جهاز صغير يعرّف الزبون **هل الكهرباء الوطنية والمولدة موجودة في بيته الآن**، مع سجل دقيق لأوقات الانقطاع والرجوع.

| الملف | الوصف |
|---|---|
| `app.html` | تطبيق الزبون (يُفتح برابطه الخاص `app.html?k=…` ويُثبَّت كأيقونة) |
| `admin.html` | صفحة البائع: إضافة جهاز، مفتاح الجهاز، رابط الزبون + QR، حالة كل الأجهزة |
| `index.html` | صفحة تعريفية؛ إن كان الزبون فتح رابطه سابقًا تنقله لتطبيقه مباشرة |
| `firmware/` | برنامج ESP32 وطريقة التوصيل (انظر `firmware/README.md`) |

## كيف يعمل
```
موديول كشف 220V ─► ESP32 ─(HTTPS كل تغيّر + كل 30 ث)─► wm-api (Supabase) ◄── تطبيق الزبون / صفحة الإدارة
```
- كل جهاز له **مفتاح جهاز** (للإرسال فقط) و**رابط زبون** (للعرض فقط)، ويمكن تجديد أي منهما من صفحة الإدارة.
- صفحة الإدارة تحتاج **مفتاح الإدارة**، وهو غير موجود في هذا المستودع.
