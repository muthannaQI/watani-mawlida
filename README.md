# وطني ومولدة ⚡⚙️

تطبيق + جهاز صغير يعرّف صاحب البيت **هل الكهرباء الوطنية والمولدة موجودة الآن**، مع سجل دقيق لأوقات الانقطاع والرجوع.
**البيانات تُحفظ في Google Sheet داخل حساب الزبون فقط** — لا خادم ولا قاعدة بيانات خارجية.

| الملف | الوصف |
|---|---|
| `app.html` | تطبيق الزبون (يُفتح برابطه الخاص `app.html?s=…&k=…` ويُثبَّت كأيقونة) |
| `index.html` | صفحة تعريفية؛ إن كان الزبون فتح رابطه سابقًا تنقله لتطبيقه مباشرة |
| `google/` | سكربت Google Apps Script للملف + خطوات الإعداد (انظر `google/README.md`) |
| `firmware/` | برنامج ESP32 وطريقة التوصيل (انظر `firmware/README.md`) |

## كيف يعمل
```
موديول كشف 220V ─► ESP32 ─(HTTPS عند كل تغيّر + كل 60 ث)─► Apps Script ─► Google Sheet (حساب الزبون)
                                                                   ▲
                                              تطبيق «وطني ومولدة» يقرأ منه
```
- الجهاز يكتب بـ **Device key**، والتطبيق يقرأ بـ **مفتاح عرض** مختلف؛ ويمكن تجديدهما من قائمة الملف.
