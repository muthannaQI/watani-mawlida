# جهاز «وطني ومولدة» — ESP32

جهاز صغير يُركَّب في لوحة الكهرباء، يقرأ **وجود** الكهرباء الوطنية وخط المولدة فقط (0 أو 1، بدون قياس الاستهلاك)، ويرسل الحالة للتطبيق فور تغيّرها وكل 30 ثانية.

> ⚠️ **التوصيل على 220 فولت يقوم به كهربائي مختص فقط**، والكهرباء مفصولة، مع فيوز صغير (0.5–1 أمبير) قبل كل مدخل.

## القطع

| القطعة | العدد | ملاحظة |
|---|---|---|
| ESP32 DevKit (ESP32-WROOM-32) | 1 | |
| موديول كشف جهد AC 220V بعازل ضوئي (Optocoupler PC817) – قناتين | 1 | أو موديولين بقناة واحدة |
| شاحن USB 5V صغير + كيبل | 1 | لتغذية الـ ESP32 |
| فيوز 0.5–1A مع حامل | 2 | واحد لكل خط |
| علبة بلاستيك عازلة + أسلاك | — | |

## التوصيل

```
 الوطنية (بعد المقياس)  L,N ──[فيوز]──► AC1 ┐
 المولدة (بعد قاطع الاشتراك) L,N ──[فيوز]──► AC2 ┘ موديول الكشف
                                             │
                     VCC ─► 3V3   GND ─► GND │  OUT1 ─► GPIO32  (الوطنية)
                                             │  OUT2 ─► GPIO33  (المولدة)
```

- خذ الوطنية **قبل** مفتاح التحويل (السويچ) ، والمولدة من خط الاشتراك **قبل** السويچ، حتى يُقرأ كل مصدر وحده.
- غذِّ الموديول من **3V3** (وليس 5V) حتى لا تتجاوز إشارة OUT جهد الـ ESP32.
- إذا لم يكن عند الزبون مولدة: اترك GPIO33 فارغًا وأزل علامة «يوجد اشتراك مولدة» من صفحة الإدارة.

### تغذية الجهاز (مهم)
يجب أن يبقى الجهاز **والراوتر** شغّالين عندما تنقطع الوطنية والمولدة معًا، وإلا لن يصل خبر الانقطاع:
- إذا عند الزبون منظومة شمسية/انفرتر: شغّل الشاحن والراوتر من مخرج الانفرتر.
- وإلا: استعمل **UPS صغير للراوتر** (الشائع في الأسواق) وغذِّ منه الـ ESP32 أيضًا.

## برمجة الجهاز (مرة واحدة)
1. ثبّت **Arduino IDE**، ثم من Boards Manager ثبّت **esp32 by Espressif**.
2. من Library Manager ثبّت **WiFiManager by tzapu**.
3. افتح `watani-mawlida/watani-mawlida.ino`، اختر اللوحة **ESP32 Dev Module** ثم Upload.

## إعداد الجهاز عند الزبون
1. من **صفحة الإدارة** أضف الزبون ← تحصل على **مفتاح الجهاز** و**رابط الزبون + QR**.
2. شغّل الجهاز ← يظهر واي فاي باسم **`Watani-Setup`** (الضوء الأزرق يرمش بسرعة).
3. اتصل به من الموبايل ← تفتح صفحة الإعداد (أو افتح `192.168.4.1`).
4. **Configure WiFi** ← اختر واي فاي البيت، اكتب كلمة السر، والصق **مفتاح الجهاز** ← Save.
5. خلال ثوانٍ يظهر الجهاز «متصل» في صفحة الإدارة، وأعطِ الزبون الرابط/QR ليثبّت التطبيق.

## الضوء الأزرق
| الضوء | المعنى |
|---|---|
| يرمش بسرعة | وضع الإعداد (`Watani-Setup`) |
| يرمش ببطء | لا يوجد واي فاي |
| ومضة قصيرة كل ثانيتين | متصل بالواي فاي لكن الخادم رفض/لم يرد (تأكد من المفتاح) |
| ثابت | كل شيء يعمل |

**إعادة ضبط:** اضغط زر **BOOT** مطوّلًا 5 ثوانٍ ← يُمسح الواي فاي والمفتاح ويعود وضع الإعداد.

## ملاحظات تقنية
- العينات تُقرأ كل 100 ms (موجات 50 Hz تجعل خرج العازل الضوئي نبضيًا)، والحالة الجديدة تُعتمد بعد ثبوتها ثانيتين.
- مع كل إرسال يُرسل الجهاز `grid_for` / `gen_for` (منذ كم ثانية الحالة الحالية)، فيُسجَّل وقت الانقطاع الصحيح حتى لو تأخر الإنترنت.
- إذا كانت الموديولات عندك تعطي HIGH عند وجود الكهرباء، غيّر `ACTIVE_LOW` إلى `false`.
